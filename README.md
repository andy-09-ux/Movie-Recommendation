# 🎬 CineMood AI

A mood and genre-based movie recommendation system built using Machine Learning.

## Features
- Mood-based movie recommendations
- Genre selection
- TF-IDF and Cosine Similarity
- Movie posters using the OMDb API
- Responsive web interface

## Technologies
- Python and Flask
- HTML, CSS, JavaScript
- Pandas, NumPy, Scikit-learn
- MovieLens dataset
- OMDb API

## How to Run

Install the dependencies:

```bash
pip install flask pandas numpy scikit-learn requests
```

Set your OMDb API key as an environment variable, then run:

```bash
python app.py
```

Open `http://127.0.0.1:5000` in your browser.
